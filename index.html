📦 Como agregar un mazo nuevo
1. Entra a supabase.com → Storage y crea un bucket publico, por ejemplo: CARTAS-MADERA
2. Subi las 40 imagenes con estos nombres exactos:
1-espadas.jpeg   2-espadas.jpeg   ...   7-espadas.jpeg
1-bastos.jpeg    2-bastos.jpeg    ...   7-bastos.jpeg
1-oros.jpeg     2-oros.jpeg     ...   7-oros.jpeg
1-copas.jpeg    2-copas.jpeg    ...   7-copas.jpeg
sota-espadas.jpeg   caballo-espadas.jpeg   rey-espadas.jpeg
sota-bastos.jpeg    caballo-bastos.jpeg    rey-bastos.jpeg
sota-oros.jpeg     caballo-oros.jpeg     rey-oros.jpeg
sota-copas.jpeg    caballo-copas.jpeg    rey-copas.jpeg
reverso.jpeg
3. Edita el array MAZOS en el codigo JS y agrega tu entrada:
{ id: 'madera',
  nombre: 'Madera',
  desc: 'Diseno rustico',
  folder: 'CARTAS-MADERA',  ← nombre del bucket
  ext: 'jpeg',
  color: '#5D4037',
  preview: '🪵' }
⚠️ El bucket debe ser publico (Public bucket) y las imagenes deben ser accesibles sin autenticacion. Si usas .png en vez de .jpeg, cambia el campo ext.
📖 Reglas del Truco
🎴 La Muestra

Al repartir, la 7ª carta queda boca arriba — esa es la muestra. Su palo define las Piezas: el 2, 4, 5, Caballo y Sota de ese palo valen más que todo en truco.

2 › 4 › 5 › Cba › Sota (muestra) › 1♠ › 1♣ › 7♠ › 7◎ › 3 › 2 › 1 › Rey › Cba › Sota › 7 › 6 › 5 › 4
⚔️ Truco (Gritos)

En tu turno podés gritar Truco. El rival puede: Quiero (+2 pts a ganador de mano), No quiero (perdés 1 pt) o subir a Re-Truco (3 pts). El que recibe el Re-Truco puede subir a Vale Cuatro (4 pts).

🎯 Envido (Toques)

Solo en la primera ronda, incluso si ya se gritó Truco. Opciones: Envido (2pts), Real Envido (3pts), Falta Envido (pts que faltan al que va primero).

Pieza 2=30 · 4=29 · 5=28 · Cba/Sota=27 · Dos mismo palo +20 · Negras (S/C/R)=0
🌸 Flor (Cantos)

Tenés Flor si: 2+ piezas · 1 pieza + 2 cartas del mismo palo · 3 cartas del mismo palo. Vale 3 pts automáticos y cancela el envido. Si los dos tienen Flor: el mano canta "¡Flor!" y el otro puede responder "También Flor" (gana el de más puntos, 6 pts) o subir a "Contra Flor al Resto" (se juega todo lo que falta para los 30, +6). Si no se quiere la Contra Flor al Resto, el que la cantó se anota 6 pts igual.

🃏 Al Mazo · Mano y Pie

Tirarse al mazo = ceder 1 pt al rival. Gana la mano quien gana 2 de 3 rondas. En caso de parda, lidera la siguiente ronda quien lideró esa. La mano se alterna cada partida. Si se discutió Envido o Flor, las cartas que no se llegaron a jugar se dan vuelta automáticamente al final de la mano para verificar los puntos.

⚙️ Configuración Online

Solo necesario para el modo multijugador
📋 PASO 1 — Crear tabla en Supabase
Copiá este SQL en supabase.com → SQL Editor → New Query
CREATE TABLE IF NOT EXISTS games ( code TEXT PRIMARY KEY, state JSONB NOT NULL, updated_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE games ENABLE ROW LEVEL SECURITY; CREATE POLICY "allow_all" ON games FOR ALL USING (true) WITH CHECK (true); ALTER PUBLICATION supabase_realtime ADD TABLE games;
🔑 PASO 2 — Tus credenciales de Supabase
